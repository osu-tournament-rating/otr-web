Welcome to the o!TR Docs! Our documentation may be browsed online [here](https://docs.otr.stagec.net/). All documentation for the o!TR project, including otr-web, is hosted there.

The docs live in `apps/docs` of the [otr-web](https://github.com/osu-tournament-rating/otr-web) repository and use [Quartz](https://quartz.jzhao.xyz/) to render and serve our files to the web. Quartz is included at `apps/docs/quartz` as a [git submodule](https://git-scm.com/book/en/v2/Git-Tools-Submodules).

The [Team](https://docs.otr.stagec.net/About/Team) is not affiliated with Quartz in any way. To view our original work, please browse to the `./docs` directory. The `quartz` directory is only used during deployment, feel free to ignore it.
