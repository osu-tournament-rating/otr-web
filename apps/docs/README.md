Welcome to the o!TR Docs! Our documentation may be browsed online [here](https://docs.otr.stagec.net/). All documentation for the o!TR project, including otr, is hosted there.

The docs live in `apps/docs` of the [otr](https://github.com/osu-tournament-rating/otr) repository and use [Quartz](https://quartz.jzhao.xyz/) to render our files for the web. The Docker image builds the site with an unmodified copy of Quartz and serves it with nginx.

The [Team](https://docs.otr.stagec.net/about/team) is not affiliated with Quartz in any way. To view our original work, please browse to the `./docs` directory. The other files configure how Quartz builds the site, feel free to ignore them.
